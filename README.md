# Image to Text Extraction Using Streamlit, EasyOCR, and OpenCV

This repository hosts a Python-based **Image-to-Text Extraction Project** that leverages the following technologies:

- **Streamlit**: For building an intuitive and interactive user interface.
- **Pillow (PIL)**: For image handling and processing.
- **EasyOCR**: For Optical Character Recognition (OCR) to extract text from images.
- **OpenCV**: For image preprocessing and enhancement.

## Features
- **User-Friendly Interface**: Upload images directly through the Streamlit interface.
- **Text Extraction**: Automatically detects and extracts text from uploaded images using EasyOCR.
- **Image Processing**: Preprocess images for improved OCR accuracy using OpenCV.
- **Multi-Language Support**: EasyOCR supports multiple languages for text recognition.

## How It Works
1. Users upload an image via the Streamlit web app.
2. The image is displayed within the app for preview.
3. EasyOCR processes the image to extract text.
4. Preprocessing techniques using OpenCV ensure high accuracy.
5. Extracted text is displayed on the screen for copying or saving.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/image-to-text.git
   ```
2. Navigate to the project directory:
   ```bash
   cd image-to-text
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   streamlit run app.py
   ```

## Requirements
- Python 3.7+
- Streamlit
- EasyOCR
- OpenCV
- Pillow (PIL)
- NumPy
